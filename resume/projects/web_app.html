Overview

This started as a group project with a simple goal: build one tool that covers the different ways people actually study, instead of switching between five different apps. The result was a full-stack academic productivity platform that combines a word processor, flashcards with text-to-speech, and an interactive drag-and-drop diagram tool in a single workspace.

Everything is backed by a real database and account system, so notes, flashcards, and diagrams are saved and available from any device, not just stuck in one browser tab.

My Role — Team Lead

I led a team of four on this project, which meant more than just writing my own features. I mentored teammates through Node.js, Express, and database integration as they picked those tools up, and kept an eye on scope and deadlines so the project stayed realistic for a semester timeline.

Key responsibility: Balancing hands-on development with helping teammates get unstuck on the backend, while keeping the overall feature set scoped to something we could actually finish and polish.

What I Built

  • A full-stack academic productivity platform with a built-in word processor, flashcards (including text-to-speech), and a drag-and-drop diagram tool.
  • JWT-based authentication and full CRUD functionality, with MongoDB handling persistence for user accounts, documents, and study materials.
  • A responsive frontend that holds up across both desktop and mobile, tested for consistent behavior across browsers.
  • Backend services and REST APIs connecting the frontend to the database, deployed on AWS.
